# Wearwell Closet

I was very tired to pick my outfits from my messy closet everyday so out of frustration i created this website which I can use to plan my look for college wherever i want , weather it be bus,train or anywhere . It let's u plan your outfit from the clothes u have currently available ,all u have to do is just have the photo of your clothes and upload it on the website so u can create your look .

Live demo: https://wearwell-e4e18.web.app

## Run locally

Open `index.html` through a local web server. Firebase Authentication and Firestore are configured in the page for the Wearwell project.
