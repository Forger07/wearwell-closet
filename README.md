# Wearwell Closet

Wearwell is a personal digital wardrobe and outfit planner. Users can create an account, organize clothing by category, save outfit memories, and plan looks from items they own.

Live demo: https://wearwell-e4e18.web.app

## Run locally

Open `index.html` through a local web server. Firebase Authentication and Firestore are configured in the page for the Wearwell project.
